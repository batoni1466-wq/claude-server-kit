# ClaudeCode — свой сервер с Claude в браузере для команды

Это готовый комплект, чтобы поднять **свой сайт с Claude** — где вся команда заходит в
браузере, без VPN, каждый под своим логином. Плюс, по желанию, **Claude Design** —
ИИ-инструмент дизайна, и генерация картинок через **ChatGPT**. Всё работает на твоих
подписках (Claude, ChatGPT), никаких API-ключей.

## Что это даёт

- Свой адрес (например `https://203-0-113-45.sslip.io`), команда заходит из России без VPN.
- Одна подписка Claude на всех, но у каждого свой логин, своя папка, свои чаты — чужого не видно.
- Верхняя надпись — **ClaudeCode** (можно поменять на своё название).
- По желанию: Claude Design (дизайн) + картинки через ChatGPT.

## Что понадобится

1. Аккаунт на **Timeweb** — [timeweb.cloud](https://timeweb.cloud/?i=144973). Там создаётся
   сервер. Хватает простого: 2 ГБ памяти, от 20 ГБ диска, локация Нидерланды — 1200-1600 ₽/мес.
   Дороже брать не надо, если не нужен Claude Design.
2. Подписка **Claude** (лучше Max — лимит делится на всю команду).
3. (по желанию) Подписка **ChatGPT** — только если нужны ИИ-картинки в дизайне.
4. **VPN** на компьютере — нужен всего на 1 минуту при входе в Claude/ChatGPT.

> **Маленькая просьба.** У меня самого команда работает на сервере Timeweb, так что советую
> то, чем пользуюсь. Ссылка выше — моя реферальная. Буду благодарен, если заведёшь аккаунт
> по ней: тебе это ничего не стоит, платишь обычную цену по прайсу, а мне хостер начислит
> небольшой бонус. Комплект я собрал и отдаю бесплатно — если он тебе пригодился, такая
> мелочь будет приятной поддержкой. А не хочется — открывай timeweb.cloud напрямую, всё
> соберётся ровно так же, никаких обид.

## Как запустить — самый простой путь

**Скорми этот архив Claude Code** (открой папку в Claude Code или распакуй архив и укажи её)
и напиши: **«Разверни мне это по инструкции INSTALL-AI.md»**.

Claude прочитает [INSTALL-AI.md](./INSTALL-AI.md) и сделает всё сам, по шагам:
создаст ключ доступа, подскажет что нажать на Timeweb, сам зайдёт на сервер, всё установит,
покажет ссылку для входа в твой Claude (тут понадобишься ты — открыть ссылку с VPN и прислать
код), заведёт пользователей и проверит, что всё работает. Тебе останется только заходить.

## Главное правило: ты не работаешь в терминале

Ты **не набираешь команды сам**. Ты открываешь эту папку как проект в Claude Code (или
Codex) и просто **пишешь в чат, что нужно** — Claude сам заходит на сервер и всё делает.
Так же, как ты уже привык работать с Claude.

Дальше, когда сервер поднят, всё управление — это фразы в чат:

- «Заведи пользователя, логин anna_ivanova, имя Анна Иванова» — Claude заведёт и пришлёт пароль.
- «Удали пользователя ivan» / «Смени пароль у anna_ivanova».
- «Панель не открывается, почини» — Claude проверит и починит.
- «Сделай бэкап» / «Обнови панель» / «Перенеси всё на новый сервер».

Твои руки нужны только там, где Claude физически не может: **клики в Timeweb** при создании
сервера и **вход в браузере с VPN** (открыть ссылку, прислать код в чат). Всё остальное — Claude.

## Что Claude делает под капотом (тебе это делать не нужно)

Для понимания, из чего состоит установка (Claude выполняет это сам по [INSTALL-AI.md](./INSTALL-AI.md)):
создать сервер на Timeweb (Ubuntu 24.04, 2 ГБ памяти, от 20 ГБ диска) → скопировать папку на сервер → заполнить
`config.env` (IP) → `install.sh` (ставит всё) → `login-claude.sh` (вход в Claude) →
`add-user.sh` на каждого человека → по желанию `setup-open-design.sh` (Claude Design).

## Честно про ограничения

- **Одна подписка = общий лимит.** Все делят лимит Claude. Много людей на одной подписке —
  против правил Anthropic (риск блокировки аккаунта). Это удобный вариант для **своей
  доверенной команды**, а не полноценный сервис на каждого со своим лимитом.
- **Изоляция — панель плюс права на файлы.** Каждый заперт в своей папке, и сама папка на
  диске закрыта: права `0700`, читает только её владелец. Посторонняя программа на сервере
  (бот, другой сервис под своей учёткой) чужие файлы не откроет и даже список логинов не
  увидит. Но панель и Claude на сервере работают от главного пользователя (root), а root
  видит всё — значит, изнутри панели подкованный человек всё ещё может попросить Claude
  заглянуть в чужую папку. Полностью это закрывают отдельные учётки на каждого
  (`ccuser_<логин>`): если они на сервере заведены, `secure-workspaces.sh` отдаёт папку
  владельцу и сессия человека работает уже от его имени. Для доверенных коллег — нормально.
- **Регион.** Доступ из России формально в серой зоне. Стабильный европейский сервер
  безопаснее «прыгающих» VPN, но гарантий нет.
